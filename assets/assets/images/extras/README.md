# Metropolitan Fitness Graphics Resources

This directory contains the graphic resources used in the application.

## club_metropolitan_logo.svg
Main logo of the application in SVG format. It features a minimalist sports design without text, using the following elements:

- Concentric circles in different colors representing focus, strength, and precision
- A stylized athletic figure at the center representing fitness and movement
- Dynamic lines showing motion and energy
- Simplified Olympic-inspired rings representing athletic tradition
- Radiating accents around the perimeter suggesting energy and impact
- Geometric details for a modern, sophisticated look

The logo uses a refined color palette that includes:
- Black (#000000) for strength and elegance
- Wine Red (#8B0000) for energy and passion
- White (#FFFFFF) for purity and cleanliness
- Various shades of gray (#666666, #888888, #AAAAAA, #CCCCCC, #DDDDDD) for sophistication and balance

The design is intentionally text-free, allowing the visual elements to communicate the brand's athletic focus and premium positioning without language barriers.

Flutter launcher icons are generated using the flutter_launcher_icons plugin.
Splash screen is generated using the flutter_native_splash plugin.
